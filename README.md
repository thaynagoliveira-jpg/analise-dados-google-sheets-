# Análise de Dados com Google Sheets

Este repositório contém um exercício prático de análise de dados utilizando o Google Sheets. O objetivo foi construir uma base de dados e, em seguida, responder a perguntas específicas aplicando fórmulas e funções nativas da ferramenta.

## 📁 Estrutura do Projeto

O arquivo **[exercicio_analise_dados_281125.xlsx](./exercicio_analise_dados_281125.xlsx)** contém:

- Uma tabela de pessoas com os campos:
  - `id_pessoa`
  - `nome_pessoa` 
  - `idade_pessoa`
  - `cidade_pessoa`
  - `status_pessoa`

- Consultas e respostas automatizadas com funções do Google Sheets

## 🛠️ Conceitos Aplicados

### Funções Utilizadas
- `CONT.SE` - Contar usuários inativos
- `MÉDIA` - Calcular média de idades
- `MAIOR` e `MENOR` - Identificar maior e menor idade
- `MÉDIASE` - Calcular média condicional por cidade
- `PROCV` - Buscar dados específicos na tabela

## 📊 Resultados

Análise completa de dados com:
- Estatísticas descritivas
- Filtros condicionais
- Sistema de consultas dinâmicas
- Relatórios automatizados
